# Eumenes経由の日本語探索SKILL配達

Eumenesの認証付き `POST /api/knowledge/skills` に、未使用の日本語4題を1回ずつ送り、レスポンスのSKILL全文を読み取るまでを計測した。4題すべてで日本語の固定本文とバイト単位で一致し、3秒以内に届いた。EumenesのHTTP処理、推論制御と受領証、保存、ContextStill v2のMCP処理を一時DBで動かし、選択には保存済み接続の実クラウドモデルを使用した。HTTPとMCPは同じプロセス内で呼び出した。[試験課題](suite.json) · [計測値](measurements.json)

| 課題 | 配達時間 | 推論の入力／出力トークン |
| --- | ---: | ---: |
| GIFのフレーム表示時間 | 1.043秒 | 652／30 |
| Markdownの表セル内の改行 | 1.348秒 | 651／32 |
| WAVの曲番号 | 1.169秒 | 642／31 |
| 図形編集の補助線への吸着 | 0.918秒 | 656／32 |

モデルは各題1回、探索SKILL配達中のContextStill呼び出しは0回。全4題で保存後の再取得、同一要求の再送、同じ要求IDで異なる入力を拒否することを確認した。初回の実クラウド試行は、Eumenesへの接続が出力スキーマを渡す一方、モデルのメッセージに選択指示を載せていなかったため、クラウド送信前に失敗した。指示をシステムメッセージとして明示した後の結果を表に記載した。

Eumenesの認証付き検索・取得APIでContextStillを実際に呼び出し、同じハンドルで検索時の版1が更新後の版2に変わり、省略のある本文を採用できないことを確認した。認証なしの検索は401だった。固定試験では公開内容だけの変更や撤回も採用を拒否した。

実クラウドの費用は0.006202 USD、過去の未確定分を含む累計は18.5316166 / 20 USD。稼働中サービスのプロセス、会話画面からの利用、サービス間の通信時間は今回の計測範囲外。
