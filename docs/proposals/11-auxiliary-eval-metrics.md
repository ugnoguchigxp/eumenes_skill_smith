# faithfulness / context relevance の補助指標

## 目的

受入判定の補助として、指針が根拠に忠実か、取得文脈が関連していたかを自動で記録します。

## 現状の問題

未測定: どちらの指標もありません。

## 提案

Ragas 型の faithfulness と context relevance を record ごとに算出し、受入判定と並べて表示します。

## 検証（採用 / 不採用）

採用判定は、提案 01 の固定タスク集合（未整備なら提案 14 の評価キット）で変更前後を同じ record から比較し、下の条件で決めます。悪化した場合は変更を戻し、不採用の理由を本ファイルに追記します。 補助指標の採否は、受入判定との相関で決めます。

## よくなったとみなす条件

補助指標が失敗例の原因の切り分けに役立つことです。

## 悪化したとみなす条件

受入判定と相関せず、読み手を誤導することです。

## やらないこと

補助指標で人手判定やタスク受入を置き換えません。 本番の ContextStill への接続、語句辞書やキーワードによる意味分岐、費用上限によるゲートは行いません。推論は Grok Bot が recorded-inference の継ぎ目を通して行います。
